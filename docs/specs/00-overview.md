# Cukka Page — Overview

## Problem Statement
Cukka is a 100% offline personal cookbook application. To comply with Google Play Store guidelines and provide users with a public product introduction, an official web presence and hosting for the Privacy Policy is required.

## Purpose
`cukka-page` serves as the official public web landing page and hosting platform for Cukka's legal documents (Privacy Policy) hosted on GitHub Pages.

## Scope
- **App Landing Page (`index.html`)**: Product introduction, feature highlights, GitHub download link, source code link.
- **Privacy Policy (`privacy.html`)**: Full COPPA and Play Store compliant privacy policy documenting 100% offline local data storage.
- **Responsive Web Design**: Clean, lightweight HTML5/CSS3 with dark/light mode preference support matching Cukka design system tokens.

## Non-Goals
- Web version of Cukka app logic (the app runs natively via Flutter).
- User login, newsletter signups, or backend analytics.
